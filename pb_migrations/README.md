# Taller de Reparaciones

## Requisitos
- Node.js 18+
- PocketBase (incluido en `backend/`)

## Cómo arrancar el backend
1. Abrir terminal en la carpeta `backend/`
2. Ejecutar `./pocketbase serve` (Windows: `./pocketbase.exe serve`)
3. Panel admin: http://127.0.0.1:8090/_/

## Cómo arrancar el frontend
1. Abrir terminal en la carpeta `frontend/`
2. Ejecutar `npm install` (solo la primera vez)
3. Ejecutar `npm run dev`
4. Abrir http://localhost:5173
